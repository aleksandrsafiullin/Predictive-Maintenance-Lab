# Causal risk sampling math utility

Implemented `output/bearings-learned-funnel-20261002/review/causal_risk_sampling_math.py` as an inert NumPy/stdlib module. Importing it performs no loading, fitting, probing, model construction, or runtime changes. Its only proposal inputs are one-dimensional `current`, `red`, and physical unit identities; no target, mask, event, time, or recording-end fields enter the API.

## API

- `build_plan(current, red, groups)` returns a frozen `SamplingPlan` containing immutable tuples. Inputs must have equal, nonzero length, finite nonnegative current, and finite positive RED thresholds. Unit identities are nonblank strings or finite real scalars, excluding booleans. Numeric identity equality follows Python (`1` and `1.0` identify one unit); strings remain distinct. First appearance determines unit order, so changing identifier spelling while preserving equivalence classes leaves the proposal unchanged.
- Risk is `current / red`, with bins `< 0.5`, `[0.5, 1)`, and `>= 1`. There are `G` units; unit `u` has `C_u` nonempty bins; bin `s` contains `n_us` rows. Each row receives `pi_i = 1 / (G C_u n_us)`. The implementation checks a disjoint exact partition, positive support, and total probability one. Each unit has mass `1/G`; each nonempty stratum has mass `1/(G C_u)`.
- `draw_batch(plan, size, rng)` returns integer row indices and their marginal row probabilities. Supply a plan from `build_plan`, a nonnegative integer size, and a NumPy `Generator`. Physical slots receive `floor(size/G)` each plus a uniformly chosen subset for the remainder, then a permutation. Within each unit, nonempty-bin slots use the same balanced construction. Rows are sampled uniformly with replacement within each selected bin. Small batches, unequal bins, absent bins, and size zero are supported. Inputs and plans are not modified; the supplied RNG advances.
- `gradient_summary(vectors, clip_limit=5, paired_vectors=None)` accepts finite saved arrays shaped `[replicate >= 2, parameter >= 1]`. It reports trace sample variance (sum of coordinate variances with `ddof=1`), mean squared vector norm as the uncentered second moment, mean vector, norm of the mean, average sample norm, clipping factors `min(1, clip_limit/(norm + 1e-6))`, and clipped trace variance/mean/norm. Optional paired arrays must share shape and replicate order. Ratios are primary variance divided by paired variance, separately raw and clipped; positive divided by zero is infinity, zero divided by zero is NaN.

## Limits and verification

Balanced slots are dependent; returned probabilities describe each position's marginal row law, not an independent joint law. A realized batch can omit units or bins when its size is small even though the proposal retains full support. Pairing is supplied by the caller and cannot be verified from numeric arrays. Statistics are descriptive empirical measurements, with no confidence, calibration, training-quality, or optimizer-equivalence claim. Arithmetic uses float64; gradient arithmetic outside its representable range is rejected. Plans should be obtained through `build_plan`, rather than constructed manually.

Invented-input checks cover exact masses, boundary bins, empty-bin handling, randomized slot balance, empirical marginal frequencies, renaming invariance, input preservation, and hand-computable raw/clipped gradient statistics. No real dataset, model, snapshot, tensor, or NPZ was accessed. Independent review remains separate from these implementation checks.
