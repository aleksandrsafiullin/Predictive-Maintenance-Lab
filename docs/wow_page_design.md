# Bearing intelligence — page design

The operational page is a dark scientific workspace built around one story: incoming measurements drive the anatomical reservoir, which produces a changing failure window. The anatomy and charts are the main content, with execution controls and four short status cards above them.

- Canvas `#080d15`; panels `#101925`; borders `#263447`.
- Primary text `#edf4fa`; secondary text `#8fa3b7`.
- Observed signal: cyan `#61d8ee`. Forecast: amber `#f2be68`. Evaluation truth: coral `#ff7e83`.
- One restrained hero, one compact control deck, four KPI cards, then two framed panels in a 43:57 ratio. Mobile stacks these sections.
- Brain and forecast panels share a 570 px content height. Numbered section labels describe their roles. Model and unit setup moves into the sidebar.
- The brain is a real anatomical context with all computing neurons. Activity is actual model state. No decorative activity or fabricated positions.
- Three chart regions separate sensor observations, the predicted failure window, and forecast evolution. Future horizon cannot compress observed sensor history.
- Technical readout details remain in the existing inspector. Evaluation limitations are placed in a compact explanatory footer, not repeated between every visual.

The redesign changes presentation only. Start, pause, step, reset, seeking, ground truth isolation, continuous history, and forecast mathematics retain their existing semantics.
