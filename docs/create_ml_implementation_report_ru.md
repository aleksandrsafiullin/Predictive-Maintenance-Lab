# Выполнение плана Create ML workflow

Дата: 29 сентября 2026 года. Статус: реализация и интеграционная проверка завершены.

Этот отчёт фиксирует первоначальную поставку Create ML workflow. Изменения карточек импорта, переноса оборудования и редактора порогов в последующих коммитах проверены отдельно: [ревью версии `86504dd` и исправление замечаний](create_ml_review_20260929_ru.md). Указанные ниже 581 успешный тест и браузерные проверки относятся к первоначальной поставке; после исправлений актуальный полный прогон — **718 passed**, два прежних предупреждения PyTorch.

## Что изменилось

1. **Projects:** постоянный список, создание проектов с независимыми данными и моделями, восстановимое удаление. Bearings и Filters подключаются к существующим данным без копирования многогигабайтных исходников.
2. **Import data:** выбор папки через браузер или путь на компьютере приложения. Validation и Testing независимо выделяются автоматически или загружаются из отдельных папок. Для других типов оборудования добавлен формат Sensor CSV.
3. **Data Quality:** три видимые вкладки, состав выборок, пропуски, график и таблица измерений выбранного оборудования. Технические манифесты не выводятся в основной интерфейс.
4. **Training:** один выбранный движок — GRU, LSTM или quantile boosting; параметры, фоновое обучение, остановка и сохранение модели. Validation участвует в выборе модели, Testing используется после выбора.
5. **Results:** один отчёт. Серая линия фактических измерений, синий прогноз, жёлтый/красный пороги и курсор Now. Play/Pause/Reset и ползунок управляют последовательной подачей данных. Отдельно показаны недостаток истории, отсутствие прогнозируемого пересечения и уже наступившая красная зона.

План и реализацию проверяли независимо. Работу выполняли субагенты GPT-6 SOL; оркестратор проверял контракты, интеграцию и приложение в браузере. [План](create_ml_implementation_plan_ru.md), [технические задания и ревью](../.cursor/tasks/create-ml-workflow-20260929/master-plan.md), [руководство](create_ml_workflow.md).

## Исправления, найденные при ревью

- Устранены несогласованность источника/снимка при неудачном повторном импорте, ошибки группировки ZIP и недопустимые часы HSE.
- Добавлены проверки принадлежности модели и файлов, защита от ссылок за пределы проекта, блокировка удаления во время работы процесса и проверка идентификатора при остановке.
- Исправлены разрывы на графиках, привязка воспроизведения, названия сохранённых моделей, готовность обучения и контраст светлой темы.
- Старые UI-тесты исследовательских экранов перенесены на явный тестовый вход сохранённых функций. Их проверки сохранены; старый переключатель отчётов в новый продуктовый интерфейс не возвращён.

## Границы результата

Это проверка работающего приложения, а не сертификация качества промышленного прогноза. Браузерный GRU обучался только 5 эпох для проверки сценария; пороги 1/2 g были заданы для этой проверки. Полное обучение на исходных многогигабайтных XJTU-фрагментах в рамках приёмки не повторялось; адаптеры проверены тестами, существующие подготовленные данные открыты в браузере.

Прогноз времени красной зоны имеет дискретность заданных горизонтов и не означает достоверный момент механического отказа. Квантили boosting не имеют подтверждённой вероятности покрытия. Fly, Random и Full MaleCNS сохранены в исследовательском коде, но для нового числового прогноза пока недоступны. Пропускная способность воспроизведения на значительно более крупных снимках отдельно не измерялась. Удалённые проекты сохраняются с квитанцией; кнопки восстановления в этой версии нет.
