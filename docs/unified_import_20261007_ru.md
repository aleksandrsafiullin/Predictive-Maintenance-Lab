# Единая страница Import data

Benchmark использует сохранённый sensor-снимок, зарегистрированный через
source_manifest.snapshots. Старый загрузчик искал processed_fingerprint.json
по snapshot ID вместо зарегистрированного пути и показывал пустые карточки.

Все проекты теперь открывают одну полную форму Import data: сохранённые
показатели, View, папки источников, настройки распределения, Signal,
Operating age and context и Maintenance events. Формат снимка определяет
доступные категории: исторические снимки сохраняют Train/Validation/Test;
четырёхкатегорийные снимки включают Calibration.

При ошибке чтения сохранённых данных карточки показывают недоступность,
а форма остаётся доступной для восстановления через повторный импорт.
Обзор читает только метаданные. View открывает только выбранную категорию.
Повторный импорт четырёх категорий передаётся обычному project_import worker;
ошибка не заменяет предыдущий снимок и выбранную модель.

Сохранённые модели и настройки Calibration вновь доступны через их
совместимые адаптеры. Пределы полной ширины коридора остаются 20–45%.
Общая ширина страниц согласована с чатом «Очистить экран прогноза»: 1600px.
При узком окне четыре карточки распределяются по двум колонкам.
