# Коридор тренда: контракт и проверка 5 октября 2026

В Training оставлена одна задача **Trend corridor**. Все четыре движка выдают
нижнюю и верхнюю границы. Отдельная модель First RED entry в этой задаче не
обучается: окно события следует из пересечений границ с действующим порогом.
Старые сохранённые модели и исследовательские CLI сохранены.

## Ширина и обучение

- После уточнения пользователя новый контракт v2 задаёт **±10%** от уровня
  прогноза с обучаемым расширением до **±15%**. Полная ширина
  `(upper − lower) / abs(level)` составляет 20–30%.
- Сохранённый контракт v1 сохраняет исходные ±5–7,5% (полная ширина 10–15%).
  Версия контракта определяет декодирование модели при повторной загрузке.
- Ограничение встроено в выход модели и используется в функции потерь.
  В Results нет обрезания широких старых прогнозов или расширения по ошибкам.
- Для неотрицательных сигналов положительное преобразование уровня сохраняет
  положительную нижнюю границу; она не обрезается по нулю.
- Обе границы обучаются по interval score с дополнительным штрафом за расширение
  сверх базовых ±10%. Промахи остаются ошибками; неизвестные цели маскируются до арифметики.
- Цель — фактический записанный сигнал. Ретроспективное сглаживание и подгонка
  коридора к будущей серой линии не применяются.
- Вход — последние непрерывные измерения сигнала. Нормализация и деревья обучаются
  только на Train. Validation выбирает веса; Test не участвует в выборе.
- Оборудование получает равный вес; доступные горизонты и наблюдения внутри него
  получают равный вес. Полная траектория оценивается только при полном наблюдении.
- GRU/LSTM учат рекуррентный кодировщик и границы; boosting поставляет Train-only
  квантильные признаки обучаемой головке коридора. Full MaleCNS использует полный
  официальный граф с фиксированной динамикой и обучаемую головку коридора.

## First RED entry

Для верхнего RED-порога верхняя граница задаёт наиболее ранний возможный вход;
нижняя — срок, к которому вход должен произойти, **если фактический сигнал
остаётся внутри коридора**. Для нижнего порога роли границ меняются.
Результат сохраняет дискретную неопределённость между соседними отсчётами.
Если вторая граница не пересекается, конец окна открыт. Уже наблюдавшийся RED
не выдаётся как первый будущий вход. Отсутствие пересечения внутри горизонта
не означает отсутствия RED позже.

Это условное следствие геометрии коридора, а не квантиль обученной вероятности
времени события. Гарантия покрытия и производственное принятие остаются false.

неудовлетворительным**. Эти использованные ранее разделы не являются новой
независимой проверкой. Смена ширины не даёт гарантии попадания.

не опускается ниже 0,481 г; 8 из 120 будущих измерений попали в коридор (6,67%).

не пересекает порог в этом горизонте, поэтому конец RED-окна открыт.

точки совпали. Новые артефакты: `output/trend-corridor-v2-20261005/`.
Training и Results обозначают полуширину символом ±; метрика средней ширины
тоже показывает полуширину, а сохранённые численные метрики продолжают
содержать полную относительную ширину.
